# 프롬프트 생성기

**AI에게 일 잘 시키는 법, 몰라도 됩니다.**
폼에 몇 가지만 적으면, Claude · ChatGPT · Gemini에 붙여넣을 수 있는 고품질 프롬프트가 만들어집니다.

## 이런 분을 위한 도구예요

- AI한테 뭘 어떻게 물어봐야 할지 막막한 분
- 매번 프롬프트를 처음부터 쓰는 게 번거로운 분
- 잘 다듬어 둔 나만의 프롬프트를 재사용하고 싶은 분

개발 지식이 전혀 없어도 쓸 수 있도록 만들고 있습니다.

## 특징

- **설치가 필요 없어요.** 파일 하나(`index.html`)를 받아서 더블클릭하면 끝.
- **인터넷이 없어도 돼요.** 오프라인에서 완전히 동작합니다.
- **입력한 내용은 내 PC 밖으로 나가지 않아요.** 서버도, 로그인도, 수집도 없습니다.

## 사용 방법

> 🚧 **아직 개발 중입니다.** 첫 사용 가능 버전이 나오면 여기에
> "받는 법 → 여는 법 → 쓰는 법" 3단계 안내가 올라옵니다.
> 자세한 사용법은 [사용설명서.md](사용설명서.md)에서 안내할 예정입니다.
