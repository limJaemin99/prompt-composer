# 프롬프트 생성기

**AI에게 일 잘 시키는 법, 몰라도 됩니다.**
폼에 몇 가지만 적으면, Claude · ChatGPT · Gemini에 붙여넣을 수 있는 고품질 프롬프트가 만들어집니다.

## 3단계로 시작하기

### ① 받는 법

- **팀에서 파일을 받았다면** (기본 경로): 메신저·메일·공유폴더로 받은
  `index.html` 파일을 내 PC 아무 곳에나 저장하세요. **그게 전부예요.**
- **직접 내려받는다면**: [GitHub Releases](https://github.com/limJaemin99/prompt-composer/releases)에서
  최신 버전의 `index.html`을 내려받으세요.

### ② 여는 법

저장한 `index.html`을 **더블클릭**하세요. 크롬(Chrome)이나 엣지(Edge)로 열리면 준비 끝.
설치도, 로그인도, 인터넷도 필요 없어요.

### ③ 쓰는 법

**카드 고르기 → 빈칸 채우기 → [프롬프트 복사] → AI 채팅창에 붙여넣기(Ctrl+V)**

자세한 단계별 안내는 **[사용설명서.md](사용설명서.md)** 를 보세요.

## 이런 도구예요

- **설치 0** — 파일 하나로 끝. 오프라인에서 완전 동작
- **입력 내용은 내 PC 밖으로 나가지 않아요** — 서버·로그인·수집 없음
- **작업 유형 9종** — 이메일, 보고서, 요약, 번역, 아이디어, 엑셀, 이미지, 코드, 자유 입력
- **내 프롬프트** — 잘 다듬은 나만의 프롬프트를 등록해 변수만 바꿔 재사용 (JSON으로 팀과 공유)
- **고급 옵션** — "붙여넣는 곳의 AI가 먼저 다듬고 답하게 하기" 체크박스 / [프롬프트 지금 다듬기 (내 API 키)](docs/BYOK_가이드.md)
