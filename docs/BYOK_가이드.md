# 내 API 키로 다듬기 — 발급부터 문제 해결까지

> 이 기능은 **선택 사항**이에요. 키가 없어도 프롬프트 생성기의 모든 기본 기능은 그대로 쓸 수 있습니다.
> 키를 등록하면 결과 화면에 **[프롬프트 지금 다듬기 (내 API 키)]** 버튼이 생기고,
> 누르는 즉시 AI가 요청문을 다듬어서 보여줘요.

## 어느 회사 키를 쓸까요?

| | Google | Anthropic |
|---|---|---|
| 비용 | **무료로 시작 가능** (무료 등급 제공) | 유료 (선결제 필요) |
| 발급 난이도 | 쉬움 (Google 계정만 있으면 됨) | 쉬움 (카드 등록 필요) |
| 추천 대상 | 처음 써보는 분 | 이미 Anthropic을 쓰고 있는 분 |

**둘 다 등록하면 Google 키가 먼저 사용돼요** (무료이니까요).

## Google 무료 키 발급하기

1. [Google AI Studio](https://aistudio.google.com/)에 접속해 Google 계정으로 로그인하세요.
2. 왼쪽 메뉴(또는 우상단)의 **"Get API key"** 를 누르고 **"API 키 만들기"** 를 선택하세요.
3. 만들어진 키를 복사하세요.
   - 키가 **`AQ.`로 시작해도 정상**이에요. 예전 안내글에는 `AIza`로 시작한다고 나와 있지만,
     요즘 발급되는 새 형식이 `AQ.`입니다. 둘 다 그대로 쓰면 돼요.
4. 무료 등급은 분당 사용 횟수 제한이 있지만, 이 도구의 "다듬기" 용도로는 충분해요.

## Anthropic 유료 키 발급하기

1. [Anthropic Console](https://console.anthropic.com/)에 가입·로그인하세요.
2. **Billing**에서 결제 수단을 등록하고 크레딧을 선결제하세요(최소 $5 수준).
   - 참고: 이 도구의 다듬기는 가장 저렴한 모델(Haiku)을 쓰고, 1회에 수천 토큰 정도라
     **1회당 몇 원 미만**이에요. $5면 사실상 수백~수천 번 쓸 수 있습니다.
3. **API Keys**에서 키를 만들고 복사하세요 (`sk-ant-`로 시작).

## 도구에 등록하기

1. 프롬프트 생성기 오른쪽 위 **⚙(설정)** 을 누르세요.
2. 복사한 키를 해당 칸에 붙여넣고 **[저장]**.
3. 아무 유형이나 프롬프트를 만들어 결과 화면으로 가면
   **[프롬프트 지금 다듬기 (내 API 키)]** 버튼이 보여요.
4. 누르면 잠시 후 다듬어진 프롬프트로 바뀌고, 코드 상자 위에
   **"✨ 내 API 키로 다듬은 프롬프트"** 배지가 떠요. 마음에 안 들면 **[되돌리기]**.

## ⚠️ 주의사항 — 키는 비밀번호처럼 다루세요

- **키를 아는 사람은 내 계정으로 AI를 쓸 수 있어요** (= 내 돈이 나갈 수 있어요).
  메신저·메일로 키를 보내지 마세요.
- 키는 **이 PC의 브라우저에만** 저장되고, 해당 AI사 API 호출 외에는 어디로도 전송되지 않아요.
- 공용 PC에서는 사용 후 설정에서 키 칸을 비우고 저장하면 지워져요.
- **키가 유출된 것 같다면** 즉시 폐기하세요:
  - Google: AI Studio → API keys → 해당 키 삭제 후 새로 발급
  - Anthropic: Console → API Keys → 해당 키 Disable/삭제 후 새로 발급

## 에러가 뜰 때

| 화면에 뜨는 문구 | 원인 | 이렇게 하세요 |
|---|---|---|
| "API 키가 올바르지 않아요" (401/403) | 키 오타, 폐기된 키 | 발급 사이트에서 키를 다시 복사해 설정에 저장. 앞뒤 공백이 딸려오지 않았는지 확인 |
| "요청이 너무 잦아 잠시 제한됐어요" (429) | 무료 등급의 분당 한도 | 1분 정도 기다렸다가 다시 누르기 |
| "지금 키 등급에서는 이 모델을 쓸 수 없어요(할당량 0)" | 키 등급이 해당 모델을 지원하지 않음 — **기다려도 해결 안 됨** | Google AI Studio에서 내 키의 사용 가능 모델·등급 확인. 프로젝트에 결제 설정이 필요한 경우도 있어요 |
| "연결하지 못했어요" | 인터넷 끊김 | 연결 확인 후 재시도 (다듬기 기능만 인터넷이 필요해요) |
| "응답이 너무 오래 걸려 중단했어요" | 일시적 지연 | 잠시 후 재시도 |
