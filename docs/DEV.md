# 개발 가이드 (DEV)

이 문서는 개발자용입니다. 제품 소개는 [README.md](../README.md), 사용 안내는 [사용설명서.md](../사용설명서.md)를 보세요.

## 제품 개요

비개발자 사무직도 폼 입력만으로 Claude/ChatGPT/Gemini용 구조화 프롬프트를 만들어 복사해 쓰는 도구.
서버 없는 **단일 `dist/index.html`** 산출물. 오프라인 완전 동작(`file://` 더블클릭).
개발은 핸드오프 명세서 v2(저장소 외부 관리)를 유일 기준으로 진행한다.
(v2 주요 변경: C층 "AI로 다듬어 복사" 버튼 → "AI가 스스로 다듬어 실행" 체크박스, §5.4·§6.1·§8·§10.2)

## 기술 스택

- React 18 + TypeScript + Vite + `vite-plugin-singlefile`
- 테스트: vitest
- **의존성 추가 금지** (라우터·상태관리·UI 킷·CSS 프레임워크 불필요). 꼭 필요하면 사전 승인.
- 스타일: CSS 변수 기반 일반 CSS. 외부 폰트 로드 금지(시스템 폰트 스택).

## 명령어

```bash
npm install        # 의존성 설치
npm run dev        # 개발 서버
npm run build      # dist/index.html 단일 파일 생성 (1MB 미만 목표)
npx vitest run     # 테스트
```

## 브랜치 전략 — GitHub Flow

- `main` 보호. 직접 커밋하지 않는다(초기 부트스트랩 제외).
- **마일스톤 = 브랜치 = PR.** 브랜치명: `feat/m1-pipeline`, `feat/m2-engine`, …
- 머지는 **squash merge**.
- PR 전 종료 조건: `npm run build` + `npx vitest run` 통과 → 사용자 승인.

## 핵심 설계 원칙 (요약)

1. **PromptSpec이 단일 진실 원천.** 출력 A(AI용)와 출력 B(사람용 미러)는 각각 spec에서 렌더 — B를 A에서 파생하지 않는다.
2. **사용자 입력은 verbatim.** 수집 시 1회 트림 외 어떤 가공도 금지.
3. 템플릿 고정 문구는 EN/KO 쌍(BiText) 하드코딩. 런타임 번역 0회.
4. BYOK 미설정 시 런타임 네트워크 요청 0건.
5. "내 프롬프트" 골격은 한 글자도 변형하지 않는다(플레이버·상세도 미적용).
