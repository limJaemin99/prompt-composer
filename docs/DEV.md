# 개발 가이드 (DEV)

이 문서는 개발자용입니다. 제품 소개는 [README.md](../README.md), 사용 안내는 [사용설명서.md](../사용설명서.md)를 보세요.

## 제품 개요

비개발자 사무직도 폼 입력만으로 Claude/ChatGPT/Gemini용 구조화 프롬프트를 만들어 복사해 쓰는 도구.
서버 없는 **단일 `dist/index.html`** 산출물. 오프라인 완전 동작(`file://` 더블클릭).

### 정본 명세 (2개 병행)

1. **제품 v1 명세** — 핸드오프 v2 문서(저장소 외부 관리). 기존 9유형·내 프롬프트·C층·BYOK 정제의 유일 기준.
   (v1 내 변경: C층 "AI로 다듬어 복사" 버튼 → "붙여넣는 곳의 AI가 먼저 다듬고 답하게 하기" 체크박스, §5.4·§6.1·§8·§10.2)
2. **제품 v2 증보 명세** — 「프롬프트_생성기_v2_핸드오프_v1.md」(`0_Claude Code 프롬프트/버전 2/`, 작성 2026-07-10).
   **신규 기능(기능 A 인터뷰 체크박스 M8 / 기능 B 대화 모드 M9)의 정본.** 신규 기능 범위에서 두 문서가 충돌하면 v2 문서가 우선.
   기존 원칙(하이브리드 언어·톤·문서-코드 정합·구현 전 보고)은 그대로 유효. §6에 위반 불가 불변 원칙 12개.

**제품 v1은 M0~M7 완료·배포(태그 `v1.0.0` + GitHub Release, asset: index.html).** `main`은 v2 개발 중이며, 안정판 v1 배포본은 언제든 `v1.0.0` 태그에서 재현한다.

## 기술 스택

- React 18 + TypeScript + Vite + `vite-plugin-singlefile`
- 테스트: vitest
- **의존성 추가 금지** (라우터·상태관리·UI 킷·CSS 프레임워크 불필요). 꼭 필요하면 사전 승인.
- 스타일: CSS 변수 기반 일반 CSS. 외부 폰트 로드 금지(시스템 폰트 스택).

## 명령어

```bash
npm install        # 의존성 설치
npm run dev        # 개발 서버
npm run build      # dist/index.html 단일 파일 생성 (1MB 미만 목표)
npx vitest run     # 테스트
```

## 브랜치 전략 — GitHub Flow

- `main` 보호. 직접 커밋하지 않는다(초기 부트스트랩·릴리스 준비 등 리포 설정 제외).
- **마일스톤 = 브랜치 = PR.** 브랜치명: `feat/m8-interview-checkbox`, `feat/m9-conversation`, `feat/m10-v2-finalize`, …
- 머지는 **squash merge**.
- PR 전 종료 조건: `npm run build` + `npx vitest run` 통과 → 사용자 승인.

### 릴리스·핫픽스

- 마일스톤 완료 배포 시점은 **annotated 태그 + GitHub Release**로 고정하고 `dist/index.html`을 asset으로 첨부한다(빌드 산출물은 gitignore이므로 태그 커밋에서 재빌드해 첨부).
  - `v1.0.0` = M7(제품 v1) 완료 시점.
- **v1 핫픽스가 필요하면**: `v1.0.0` 태그에서 `hotfix/*` 브랜치로 분기 → 수정 → `v1.0.1` 태그·Release. v2 개발 중인 main과 독립적으로 v1 배포본을 유지.

## 핵심 설계 원칙 (요약)

1. **PromptSpec이 단일 진실 원천.** 출력 A(AI용)와 출력 B(사람용 미러)는 각각 spec에서 렌더 — B를 A에서 파생하지 않는다.
2. **사용자 입력은 verbatim.** 수집 시 1회 트림 외 어떤 가공도 금지.
3. 템플릿 고정 문구는 EN/KO 쌍(BiText) 하드코딩. 런타임 번역 0회.
4. BYOK 미설정 시 런타임 네트워크 요청 0건.
5. "내 프롬프트" 골격은 한 글자도 변형하지 않는다(플레이버·상세도 미적용).
6. **딥 틸(#0F766E) 사용 원칙(계열 정의, 2026-07-09)**: ① 주 행동 버튼(화면당 1개) ② 활성/선택 상태 표시(탭·세그·체크박스·카드 호버) ③ 포커스 링 ④ 성공 표시. 그 외 전부 무채색. 코드박스 내 뮤티드 틸(#82B8AF)은 어두운 배경 전용 파생색.
